# Cloud Study Tracker (12-Week Learning Roadmap)

A simple but powerful study tracking application built with React to help plan and track a 12-week journey from Networking (Cisco) to AWS Cloud Certifications.

This project is designed as a real-world productivity tool and a portfolio-ready frontend application.

##  Project Overview

This Study Tracker helps users follow a structured learning path:

###  Phase 1: Networking Foundations (Weeks 1–3)
- IP Addresses, Binary, Subnetting
- OSI Model, TCP/UDP
- Cisco Networking Basics completion

###  Phase 2: AWS Cloud Fundamentals (Weeks 4–7)
- AWS Global Infrastructure
- EC2 & S3
- VPCs & Security Groups
- AWS Cloud Practitioner Exam prep

###  Phase 3: Career Starter (Weeks 8–12)
- Load Balancers & Auto Scaling
- Databases (RDS, DynamoDB)
- Real-world AWS project (S3 website hosting)
- AWS Solutions Architect exam preparation


##  Features (Current Version)

-  Weekly study planner (12-week structure)
-  Click-to-complete study blocks
-  Progress saved in browser (localStorage)
-  Visual tracking of completed study days
-  Simple, fast, and lightweight UI

##  Tech Stack

- React (Vite)
- JavaScript (ES6+)
- Tailwind CSS (optional styling)
- Browser LocalStorage (for persistence)
